** TODO [#A] t0001 Harden the save transaction before wider promotion  :safety:filesystem:
Broader =$EDITOR= claims depend on explicit privacy, durability, metadata, and
concurrency semantics.

*** DONE [#A] t0001.1 Keep temporary save files private from creation through replacement
Why: the =0666=-before-=chmod= path can briefly expose private contents under a
common umask.  Done: create siblings with no group or other access, apply the
intended final mode only after writing, preserve permissive existing modes and
umask-derived new-file modes, and leave ACL policy to t0001.5.

*** TODO [#A] t0001.2 Define safe handling for stale save siblings after a crash
Why: =SIGKILL= or power loss can leave =.inedit-*.tmp= behind.  These remnants
are now private; still document whether startup reports or ignores them.  Any
cleanup must validate the exact file rather than use a broad pattern, and must
not confuse them with intentional =#filename#= recovery snapshots.

*** TODO [#A] t0001.3 Make an explicit save create a new empty file
Why: a nonexistent target currently compares equal to its initial empty buffer.
Done: make =Ctrl-S= and =:w= create zero bytes, decide what =ZZ=/unchanged exit
do, and retain no-file-on-cancel behavior.

*** TODO [#A] t0001.4 Specify and implement the intended crash-durability guarantee
Why: file =fsync()= plus =replace()= gives atomic visibility, not necessarily
power-loss durability without a directory sync.  Done: promise and test one
clear policy, including honest handling of a post-replacement sync failure.

*** TODO [#A] t0001.5 Choose a defensible metadata and hard-link policy
Why: inode replacement can lose ownership, ACLs, xattrs, labels, and hard-link
identity even while preserving mode bits.  Done: preserve or reject each risky
case explicitly and publish and test the supported policy.

*** TODO [#A] t0001.6 Make conflict-detection claims match the actual guarantee
Why: inode/size/mtime checks miss timestamp-restored edits and cannot close the
final check/replace race.  Done: consider a content digest, document the
remaining race and lack of locking, and test whichever guarantee is claimed.

*** TODO [#A] t0001.7 Expand save failure-injection coverage
Why: write, permission, sync, close, and cleanup boundaries remain lightly
tested.  Done: inject failures at each meaningful point and assert the target
bytes, sibling state, and truthful post-replacement error report.

*** DONE [#A] t0001.8 Add private Emacs-style recovery auto-saves
Why: atomic explicit saving does not protect edits lost to a crash or signal.
Done: every 30 seconds, atomically copy a dirty buffer to private =#filename#=;
remove a session-owned snapshot after explicit save, preserve it after discard
or abnormal exit, and never overwrite a pre-existing recovery file.

** TODO [#A] t0002 Harden terminal startup, shutdown, and caller interoperability  :terminal:
Prompt-toolkit owns the live UI, but the cursor probe, retained screen, signals,
and redirected streams remain =inedit='s responsibility.

*** TODO [#A] t0002.1 Redesign the pre-render cursor-column guard
Why: the current CPR probe can consume typeahead before signal handlers are
installed.  Done: replay non-CPR bytes, close every terminal-restoration gap,
and PTY-test timeout, malformed replies, typeahead, and startup-phase signals.

*** TODO [#A] t0002.2 Resolve Git's unterminated waiting hint without erasing unrelated output
Why: reclaiming a caller's partial line could destroy legitimate output.
Done: prefer documenting =advice.waitingForEditor=false=; any reclamation must
be conservative and tested against both Git and a non-Git caller.

*** TODO [#A] t0002.3 Reconstruct final PTY screens instead of matching output fragments
Why: finding bytes in a VT stream does not prove the final cells.  Done: use a
terminal screen model to assert viewport, gutters, styles, retained sentinel,
summary row, scrolling, resize, and next-prompt placement.

*** TODO [#A] t0002.4 Expand live terminal and signal coverage
Why: one 80x24 POSIX PTY is not a terminal support matrix.  Done: cover live
resize, =SIGHUP=, narrow/short screens, long and unusual Unicode, representative
xterm-compatible terminals and multiplexers, and publish the supported scope.

*** TODO [#B] t0002.5 Decide whether to use the controlling terminal when standard streams are redirected
Why: strict TTY streams exclude some valid =$EDITOR= calls, while =/dev/tty=
fallback has portability and security costs.  Done: choose one contract and
test redirected stdin, stdout, and stderr plus dumb/SSH/container cases.

*** TODO [#B] t0002.6 Revisit retained-output privacy and configurability
Why: retained discarded text remains in scrollback.  Done: explicitly retain
the current default or add a justified erase option, then test every exit path.

** TODO [#B] t0004 Make external-editor handoff fail safely  :external_editor:

*** TODO [#B] t0004.2 Handle external temporary-file read and cleanup failures

*** TODO [#B] t0004.3 Define blocking, cursor, and undo semantics for external edits

** TODO [#B] t0005 Make the supported scope explicit and enforce resource bounds  :scope:

*** TODO [#C] t0005.3 Implement search and replace after release blockers

*** TODO [#C] t0005.4 Investigate optional system-clipboard integration after hardening

** TODO [#A] t0007 Make save-result feedback transient
